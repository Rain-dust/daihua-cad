# 出图与按需整理

仅在客户需要 PDF、打印、批量出图或性能整理时读取。先固定任务文件与输出范围；此资料不要求每次绘图启动 CAD。

## PDF 与布局

- 沿用客户模板的图纸幅面、图框、布局、比例和 CTB/STB；没有模板时按图纸用途选择。模型按真实尺寸建立，布局视口和打印比例另行控制，不能把“布满图纸”当成已验证的工程比例。
- 选择当前环境真实可用的绘图仪或导出器，例如 CAD 自带的 PDF 配置。名称、纸张和样式表随环境而异，先核实，不硬编码维护者配置。
- 按要求设置打印范围、方向、纸张、线宽、颜色、图层可打印状态。保留客户有意关闭或冻结的图层，不为出图全局解冻、全开图层。
- 沿用客户字体；缺失时查找可用字体或合适替代并核对字形、字宽、符号与换行。不能通过一律改成系统字体掩盖版式变化。
- PDF 必须来自最终 CAD 的相同内容和版面。检查裁切、缺字、标注遮挡、填充密度、尺寸符号、线宽及页面数量；按需要核对输出比例。仅确认导出命令成功或 PDF 能解析还不够。
- 无法核对的打印比例、字体或 PDF 内容一致性应列为未验证，不能宣称通过。

## 批量出图

复用已有页面设置、脚本和批处理工具，减少逐图鼠标操作。批次先在代表文件上检查输出，确认页面与文件映射后再扩展。

每个文件使用明确的文档引用，避免跟随 UI 的 ActiveDocument；只关闭本批次打开的文档，保留未授权的客户修改。逐项记录成功文件、失败原因和未完成输出，重试前检查已有文件及 CAD 忙碌状态，避免重复出图或覆盖有效结果。具体 API、等待与回读方式见 cad-automation 的对应执行资料。

## 按需整理与性能

| 症状 | 需要核对的原因 | 可选处理 |
|---|---|---|
| 打开慢 | 异常线型、字体、注册应用、外部参照或大量对象 | 定位来源后局部清理或修复 |
| 平移缩放卡 | 高密度填充、复杂曲线、过量细节 | 在不损失要求精度的前提下简化任务对象 |
| 保存慢 | 大量历史资源、嵌入数据或参照问题 | 检查实际影响后按范围整理 |
| 大文件不稳定 | 资源需求、损坏对象、参照组织等 | 结合日志处理；有项目依据时拆分参照 |

文件大小或单一症状不能证明原因。以下命令是按需选择的独立工具，不是每次交付的固定管线：

| 工具 | 用途与边界 |
|---|---|
| `_-PURGE` | 清理未引用资源；客户模板中的备用块、图层和样式可能仍有用途 |
| `_AUDIT` | 数据库检查；修复模式会改图，适用于任务文件或副本 |
| `_OVERKILL` | 整理重复或重叠对象；先限定选择范围、容差和语义，重叠也可能是有意设计 |
| `_-SCALELISTEDIT` | 需要时整理异常标注比例列表，保留项目使用的比例 |
| `_WBLOCK` | 按需导出对象或文件；不能因此丢失布局、参照、属性或其他客户结构 |

清理文字空格、拆分曲线、重建块等操作只针对明确的整理需求；保留 MTEXT 格式、字段、属性和必要空格。执行命令前按本机提示和 CAD 版本确定参数，不把示例命令串当作所有环境通用的脚本。具体恢复、选择集与命令完成验证交由 cad-automation 处理。
