# 制图约定与行业示例

仅在需要设计图层、标注、块、模板或行业图纸组织时读取。下列是原知识库的常用示例，不代表已核实的最新版国家标准；客户模板与任务适用的规范优先。引用国标版本或确定工程参数前按需要核对。已有图纸先保留其结构，示例仅用于需要新增或调整的内容。

## 第一章：CAD制图规范（国标）

### 1.1 图纸幅面 (GB/T 14689)

| 幅面 | 尺寸(mm) | 适用场景 |
|------|---------|----------|
| A0 | 841×1189 | 总图、大型工程 |
| A1 | 594×841 | 总平面、系统图 |
| A2 | 420×594 | 平面图、装配图 |
| A3 | 297×420 | 零件图（最常用） |
| A4 | 210×297 | 简单零件、明细表 |

图框、装订边和标题栏按适用标准、幅面、方向及客户模板设置，不用单一边距覆盖所有情况。

### 1.2 比例选择 (GB/T 14690)

| 类型 | 推荐比例 |
|------|---------|
| 原值 | 1:1（优先选用） |
| 放大 | 2:1, 5:1, 10:1 |
| 缩小 | 1:2, 1:5, 1:10, 1:50, 1:100 |

模型按确认单位和真实尺寸建立；按用途选择布局比例并如实标注，已有图纸比例与坐标不得静默改变。

### 1.3 图线规定 (GB/T 17450)

| 线型 | 线宽 | 用途 |
|------|------|------|
| 粗实线 | 0.5-0.7mm | 可见轮廓 |
| 细实线 | 0.18-0.25mm | 尺寸线、剖面线 |
| 虚线 | 0.25-0.35mm | 不可见轮廓 |
| 点划线 | 0.25-0.35mm | 轴线、对称线 |
| 双点划线 | 0.25-0.35mm | 假想轮廓 |

**线宽比**: 粗:中:细 = 4:2:1

## 第二章：图层管理系统

### 2.1 图层命名规范

来自"AutoCAD知识库"和工程实战的最佳实践：

```
命名格式: 专业码_主组_次组_状态
示例:    A-WALL-PRIM-D  (建筑-墙体-承重-拆除)
         M-DUCT-SUPN-N  (暖通-风管-送风-新建)
         S-STRU-COLN-E  (结构-柱-混凝土-现有)
```

### 2.2 常用图层色号示例

| 图层 | 色号 | 线型 | 说明 |
|------|------|------|------|
| 粗实线(WALL) | 7(白/黑) | Continuous | 可见轮廓 |
| 细实线(DIM) | 1(红) | Continuous | 尺寸标注 |
| 中心线(CEN) | 2(黄) | CENTER/CENTER2 | 轴线/中心线 |
| 虚线(HID) | 3(绿) | HIDDEN/HIDDEN2 | 隐藏线 |
| 剖面线(HAT) | 4(青) | Continuous | 填充图案 |
| 文字(TXT) | 5(蓝) | Continuous | 文字注释 |
| 辅助线(AUX) | 8(灰) | Continuous | 构造线 |
| 图框(TB) | 7(白) | Continuous | 图框/标题栏 |

### 2.3 图层管理

新增图层前检查同名层和已加载线型；优先复用客户模板。只有确认所需线型存在或可加载时才分配，不为创建示例层覆盖已有样式。自动化实现由 cad-automation 按当前路线完成，不要求为管理图层先连接 CAD。

### 按语义检查可编辑性

图层验收须核对实际对象的构件归属，不能仅确认图层名称存在。建筑装修图中的墙、门、窗、楼梯、吊顶、各类灯具、不同材料铺装、文字、标注须能分别选择、关闭和编辑；不得用整张 PDF/图片、导入碎线或整图单块替代原生设计。新增对象通常外观 ByLayer，按任务需要以 HATCH 表达规则填充、DIMENSION 表达原生标注、INSERT 表达重复组件；保留客户图纸的有意样式和合理块结构。检查保存后的 DWG，并抽查隔离和修改效果；详见 [可编辑 DWG 分层交付验收](../../cad-automation/references/editable-dwg-delivery.md)。

### 2.4 新建对象的图层约定

1. **按用途分层**: 墙/门/窗、标注、文字、填充等在需要独立编辑时分层，优先服从客户模板
2. **随层(ByLayer)**: 新增对象通常以随层管理颜色、线型、线宽；保留客户明确的对象级例外
3. **0层使用**: 新图的工程对象宜放语义图层；块内可按属性继承需求使用0层，不因此重分客户原图
4. **Defpoints层**: 通常不打印，不用它承载应出图的设计内容；不自动删除原有层
5. **图层状态**: 需要临时隔离时保存/恢复相关状态，不全图重置客户开关和冻结设置

## 第三章：标注标准与技巧

### 3.1 标注顺序（国标）

```
总体尺寸 → 定位尺寸 → 定型尺寸 → 公差 → 形位公差 → 粗糙度 → 技术要求
```

**标注三不原则**:
- ❌ 不封闭尺寸链（至少留一个开口环）
- ❌ 不重复标注同一尺寸
- ❌ 不将尺寸标注在虚线上

### 3.2 文字字高规范

| 幅面 | 尺寸字高 | 标题字高 | 技术要求字高 |
|------|---------|---------|------------|
| A0/A1 | 5mm | 7mm | 5mm |
| A2/A3 | 3.5mm | 5mm | 3.5mm |
| A4 | 2.5mm | 3.5mm | 2.5mm |

### 3.3 公差标注

线性公差（如 50±0.1）、极限偏差、基孔/基轴配合（如 φ50H7、φ50f6）必须来自客户或可靠设计依据，示例数值不能当作默认精度。优先使用原生尺寸与公差样式；在文字中使用符号或格式控制时，核对具体 CAD/API 支持及最终显示，不能靠覆盖文字掩盖错误几何。

### 3.4 形位公差

形位公差需按实际适用标准和设计要求表达，例如直线度、平面度、圆度、位置度、平行度、垂直度及跳动；优先使用 CAD 的公差框格等语义对象。普通 Unicode 字符只能辅助显示，不能保证与标准图形、字体和输出一致。未知的公差值与基准不能推测。

### 3.5 粗糙度标注

```
Ra 3.2  →  常见表面要求示例，不能代替实际工艺依据
Ra 6.3  →  较粗糙表面示例
Ra 1.6  →  较低粗糙度要求示例
Ra 0.8  →  较低粗糙度要求示例，不能仅据数值指定加工方法
```

## 第四章：块(BLOCK)设计规范

### 4.1 块命名规范

```
项目前缀_类别_名称_规格
示例: GB_BOLT_M16x50    (国标螺栓)
      PROJ_VALVE_GATE_DN100  (项目阀门)
      SYM_DOOR_SINGLE_900    (符号单开门)
```

### 4.2 块创建最佳实践

1. **0层建块**: 块内对象画在0层，颜色/线型设为随层(ByLayer)，插入后与当前图层匹配
2. **基点合理**: 图框→左下角，螺栓→头部中心，门→铰链中心
3. **属性>文字**: 图框标题栏用属性定义(ATT)，不要用普通文字
4. **动态块**: 需要参数驱动且目标软件支持时可使用；现有动态块应采用能保留其行为的路线

### 4.3 标题栏属性

需要可批量更新的图号、图名、比例等字段时，使用块属性或现有项目字段；不要把客户已有属性重画成普通文字。属性定义、坐标和默认值依据模板，由当前可用工具实现并回读验证。

## 第五章：模板系统 (DWT)

### 5.1 模板应包含

需要复用项目模板时，按用途选择以下内容，不为一次简单绘图创建无关资源：

- [x] 所有标准图层及线型
- [x] 标注样式（GB_DIM_35 / GB_DIM_50）
- [x] 文字样式（STANDARD→仿宋, GB_ROMANS→Romans）
- [x] 页面设置（A3/A4打印配置）
- [x] 图框+标题栏块
- [x] 常用符号块（粗糙度、基准、剖切）
- [ ] 打印样式(.ctb)

### 5.2 模板复用

优先使用客户已有 DWT 或图纸样式；只有任务需要时才创建新模板。模板路径使用本机真实路径，加载后核对字体、线型、标注和布局的可用性；不能将默认模板视为已满足客户约定。

## 第九章：行业模板速查

### 9.1 机械制图

- **零件图**: 按表达需要选择视图、剖面和必要标注；不默认给每个任务追加三视图、轴测图或未知公差
- **装配图**: 按要求组织明细表、序号及配合关系
- **四类图**: 轮廓图(WALL)→标注图(DIM)→中心线(CEN)→剖面图(HAT)

### 9.2 建筑制图

- **平面图**: 轴线→墙体→门窗→标注→文字
- **图层示例**: A-WALL / A-DOOR / A-WINDOW / A-DIM / A-TEXT
- **比例示例**: 平面/立面可采用1:100、详图可采用1:20，实际服从客户与图纸用途

### 9.3 市政/公路 (CAD学习知识库重点)

- **桩位图**: 轴线定位→桩位编号→坐标标注→桩表
- **道路纵横**: 桩号标注→坡度→高程→填挖方
- **管网**: 管径标注→流向→管底标高

### 9.4 电气制图

- **原理图**: 元件符号→连线→端子号
- **布局图**: 设备位置→线槽→标注
- **软件**: EPLAN(专用)或AutoCAD Electrical(含图库)
