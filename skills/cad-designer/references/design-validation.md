# 设计验证与检查清单

依据客户要求选取验收项；仅运行与本次成果有关的检查，不为简单离线图纸先连接 MCP 或展开全套 CAD 测试。

## 从需求建立断言

把“画对”落实到可核对的对象、几何与交付条件，例如：

- 外轮廓的关键坐标、包围范围、半径、闭合性和孔距；
- 单位、模型尺寸及需要的布局比例；
- 任务对象的类型、语义图层、块属性、标注测量值与显示文字；
- 原图修改区域与应保持的图层、布局、参照、对象结构；
- 客户要求的文件格式、版本、文件名和可编辑性。

圆角是否相切、轮廓是否闭合、重复组件是否完整等按任务决定。实体总数或图层名称存在不能代替这些断言；原图本身的无关问题也不自动扩大本次修改范围。

## 验证证据

| 层级 | 证据 | 可以证明什么 | 不能证明什么 |
|---|---|---|---|
| L1 调用结果 | 无异常、返回对象、命令已提交 | 工具接收了操作 | 几何正确或文件已完整保存 |
| L2 数量与结构 | 实体数、类型、图层和布局摘要 | 基本结构存在 | 所有对象位置、尺寸或内容完整 |
| L3 几何回读 | 保存后解析/打开，核对关键数值、类型、单位和语义图层 | 与已写断言对应的工程内容 | 未纳入断言的全部细节 |
| L4 视觉对照 | 模型、布局或所需 PDF 与参考资料对照 | 可读性、遗漏、遮挡与版面关系 | 精确尺寸或格式结构一定正确 |

以 L3 的数值与结构核对为主要证据，按用途补充视觉检查。复杂参考图与正式图纸通常需要同时检查几何和视觉。离线 DXF 可通过解析器回读与审计、对象断言及可用渲染完成相应检查；没有 CAD 打开测试时如实说明，不把它记作“AutoCAD 已打开”。

## 保存后的文件检查

- [ ] 要求的实际文件存在且非空；扩展名对应真实格式和可用版本。
- [ ] 文件可以用当前可用的解析器或 CAD 打开；记录实际采用的工具。
- [ ] 包含要求的可编辑线、弧、多段线、文字、标注等实体，而不是仅嵌入参考图片。
- [ ] 关键坐标、尺寸、比例、单位、对象关系与客户依据一致。
- [ ] 按对象语义检查图层和样式；新增对象外观符合模板，原图无关结构保留。
- [ ] 对尺寸标注同时核对测量值和显示内容；覆盖文字不能掩盖错误几何。
- [ ] 已排查任务区域中的误绘、遗漏、无意义重复与额外辅助对象。
- [ ] 要求 DWG 时实际保存/转换为有效 DWG；不能以 DXF 改名代替。
- [ ] 要求 PDF 时，内容、图名、技术说明、打印范围、字体、符号、线宽和布局与 CAD 一致。
- [ ] 外部参照、字体等依赖按交付需要核对；不盲目绑定、炸块或重新组织。
- [ ] 最终目录只含约定成果；备份、脚本、日志、预览和临时文件另放。

分层交付详见 [可编辑 DWG 分层交付验收](../../cad-automation/references/editable-dwg-delivery.md)。

## 失败后的修正

先记录失败对象、预期值、实际值与当前执行状态，再局部修复。避免不看结果就重新执行整份脚本、换接口重复创建对象或重画原图。图纸部分成功时先确定已创建范围，再清理或继续；仅清理本任务创建且可确认的对象。

同一错误在没有新依据的情况下重复发生时，停止同样的重试，检查输入、坐标、单位、工具能力或换有依据的路线。未知关键尺寸、无法访问的格式或缺失必要工具，属于待解决条件；可继续独立部分并明确未完成项，不能通过降低验收条件宣告完成。

CAD 执行中固定目标文档，按接口核对 WCS/UCS，临时状态在结束时恢复；选择集唯一命名且只清理自己创建的选择集。此类执行细节按需读取 cad-automation，离线绘图不加载或执行 COM 专用步骤。

最终说明要对应证据：采用的方案、实际文件路径、已经执行的检查及未解决问题。诸如“命令已提交”“解析通过”“通过 CAD 重开”是不同证据，不混写为全部验证通过。
