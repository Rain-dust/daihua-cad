# 冲压模具设计指导

仅在客户确实要求冲压模具时读取。先区分示意、报价、评审与可加工设计；已有模具图的局部修改不自动扩成全套设计。

## 内容组织

可按任务需要组织“模架总图、工作零件、导向定位、技术要求”，但不能把示例结构强加给所有模具。

| 模块 | 典型内容 | 核对点 |
|---|---|---|
| 模架 | 上下模座、凹模板、卸料板等 | 外形、中心基准、板厚及实际结构 |
| 工作部分 | 凸模、凹模刃口、冲裁轮廓、冲孔 | 轮廓闭合、间隙方向、孔中心距 |
| 导向 | 导柱、导套、中心线 | 位置关系与工作区干涉 |
| 定位紧固 | 螺钉、销钉、沉孔 | 与刃口、导向及装配空间的关系 |
| 标注 | 外形、孔径、定位距、工作轮廓 | 尺寸链、重复与关键尺寸遗漏 |
| 技术要求 | 材料、热处理、间隙、研磨、倒角 | 是否有客户或可靠工艺依据 |

## 设计边界

不能从“画一个冲压模具”推断出可加工全套图的全部参数。按实际用途提取材料、料厚、工序、压力机、闭合高度等影响成果的关键输入；缺失且不能推断的项目应明确待确认或待复核，继续可独立完成的部分。

示意图应注明实际示意性质；未确认的料厚、冲裁间隙、材料牌号、精度与热处理不能编造，也不能使用固定百分比作为所有材料的间隙。生产适用性需要与材料、吨位、压力中心、强度、装配及安全条件相符，未经验证不承诺可生产。保留客户原有结构，不因模板清单凭空添加导向件或其他零件。
