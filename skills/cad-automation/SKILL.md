# CAD 自动化绘图

完成实际图纸制作与交付。上游作者 Delancy；Daihua CAD 集成维护 Rain-dust。技术路线由任务决定，不默认启动 AutoCAD 或调用 CAD-MCP。

## 先确定任务，再选工具

简要提取绘制/修改范围、尺寸依据、单位、所需对象和交付格式，随后执行，不输出冗长分析。用户提供的原文件、图像与文字有冲突时先指出关键差异；关键尺寸无法可靠确定时不编造，继续不受影响的部分。格式未写明时结合原文件和用途判断；无法判断且影响方案时只确认必要缺口，不擅自加交付项。

先检查当前会话已知的 skills、项目 Python/虚拟环境、可导入绘图库、已有脚本及可用 CAD 接口/转换器。复用已知环境信息，不为每张图重新扫描或重复安装软件；无需连接 CAD 即可判断的任务，不先运行连接测试。MCP 可用不意味着每步都应调用。

| 任务 | 优先考虑 | 必要边界 |
|---|---|---|
| 新建简单二维、规则几何、尺寸可靠的图片重绘 | 用已安装的 Python/ezdxf 批量生成真实 DXF 实体 | 先判断最终格式；图片需有可靠尺寸或标定依据，不能将像素直接当毫米 |
| 修改已有 DXF | 在副本上用能保留所需对象的 DXF 库或 CAD API 修改目标对象 | 特殊对象、布局、块/属性和外参需核对保真；不因工具方便重建整图 |
| 修改已有 DWG | 选能保留原图结构的 CAD API、脚本、已配置 MCP 或专业工具 | ezdxf 不能直接编辑 DWG；不能无条件经 DXF 往返转换 |
| 复杂图纸、特殊对象、参数化三维 | 用支持所需原生对象的 CAD API、AutoLISP/.NET、专业建模工具或 MCP | 按产品/版本验证对象支持与兼容性，不预设某条技术栈必胜 |
| 主要几何规则、需 DWG/原生出图 | Python 生成几何，再用 CAD 完成补充、转换和验证 | 在早期确认真实格式转换与出图能力，避免最后才发现无法交付 |

准确性、完整性与兼容性优先，再比较执行时间、工具往返和 Token 消耗。将适合批处理的几何放入一次脚本执行；MCP 用于确有价值的交互、原生对象、回读和转换，不逐条远程调用绘制规则阵列。选定路线后只读相关资料：

- Python/DXF、图片标定、混合交付：读 [程序化二维绘图](references/programmatic-2d.md)。
- 需要 CAD/MCP 接入时：读 [本机环境接入](references/local-setup.md) 和 [CAD 执行与恢复](references/cad-execution.md)；具体 API 才查 [CAD API 配方](references/cad-api-recipes.md) 对应章节，不整份加载。
- 可编辑 DWG：读 [分层交付验收](references/editable-dwg-delivery.md)；DXF 任务按相同编辑语义取相关检查，不强加 DWG 专属操作。
- 设计、图层/标注或正式图纸用语需要规范判断时，按已安装的 cad-designer skill；冲压模具任务另读 [专项流程](references/stamping-die.md)。

## 制作约束

- 保留客户要求的比例、位置和图形关系；不加未要求的结构、尺寸、装饰或工艺参数。示意任务的假设也要说明，不能冒充客户确认的工程尺寸。
- 既有图纸先固定目标文档、对象范围和源文件，修改副本并另存；保留无关图层、布局、块、属性、外参、单位与可编辑性。用户明确要求的原位保存除外；局部修改不扩大为整图整理。
- 模型按实际单位 1:1 绘制，明确 WCS/UCS 与出图比例。新建内容按构件/用途分层，外观 ByLayer；已有图纸优先沿用原标准，不为套模板全图重设。
- 设计内容使用 LINE、ARC、LWPOLYLINE、TEXT/MTEXT、DIMENSION、HATCH、INSERT 等合适原生对象；不能把嵌图、PDF 底图、碎线文字或整图单块冒充可编辑工程图。客户要求保留的参照可单独分层。
- 输出必须是真实有效格式。DWG 由确有能力的 CAD/转换器生成，禁止改扩展名；PDF 仅作约定的出图成果。缺少必要工具时说明具体交付障碍，不能自行用 DXF/预览图替代必需 DWG。
- 不清空/关闭无关文档，不自动执行全图清理。脚本异常先核实已创建/修改的对象，回滚或确认未生效再重试；保留错误证据，不重复生成造成叠图，不反复尝试相同失败方案。

## 保存后检查与交付

从需求建立关键断言，不从生成结果抄一份期望值自证。按任务风险进行程序检查和必要的视觉核对：

1. 对照参考材料清点重要轮廓、孔、圆弧、文字、标注和组件，检查遗漏、多余及明显重复对象。
2. 回读保存文件，核对单位、关键尺寸、标注测量值、比例、位置关系、空间/图层和实体类型；确认真实可编辑实体存在。可用 [静态 DXF 检查器](scripts/audit_editable_dxf.py) 辅助图层和类型检查，其 passed 不代表尺寸、参考图一致性或视觉检查全部通过。
3. DWG 用实际 CAD/可用解析工具回读；文件存在、扩展名、文件头、工具 success 或 AUDIT 0 都不足以单独证明交付正确。转换后的最终文件也要检查，不能只验中间 DXF。
4. 要求 PDF 时，检查最终 PDF 的页数、纸幅、比例、字体、裁切、图框及关键内容与同版 CAD 一致；优先从同一最终 CAD/几何数据出图。渲染预览不等于原生 CAD 的打开或打印验证。

可修复且在任务范围内的问题直接修复，修改后重验受影响项；只在出现新修改/失败/未决疑点时重复检查。无法验证的项目明确列为未验证，缺失成果明确列为未完成，不虚报通过。

从明确的最终文件清单构建独立交付目录，保留源文件；脚本、日志、临时文件和备份放工作目录，用户要求时再纳入。最终简短说明采用的路线、实际文件及真实路径、已执行检查和未解决事项。制作任务必须交付真实生成的成果，不能只给代码或效果预览。第三方来源/许可证记录留工作资料，依法需随成果分发的声明应保留。
