# 冲压模具绘图专项

仅用于客户明确要求冲压模、落料模、冲孔模、模架、凸凹模、卸料板或导向件的任务；不自动给普通零件图增加模具结构。绘图执行按主 skill 的任务路由选择，规则二维几何可程序化生成，不要求先连接 MCP。

## 尺寸与设计依据

从客户资料提取模具类型、工件轮廓和尺寸、材料与厚度、精度/产量、压力机及交付图纸范围。图中未知的关键尺寸与工艺参数不得编造。仅在用户要求教学/能力示范或授权示意假设时采用明确声明的示例参数；示意图不能称为可加工生产全套图。

未知材料厚度时不写确定刃口间隙；间隙、吨位、闭合高度、压力中心、强度、热处理和安全参数需有适用材料/工艺与设备依据。不把固定百分比当通用工程值。

## 按客户图纸范围组织

- 总图可按模架、工作零件、导向定位、紧固及技术要求组织；平面/剖视、零件图与明细按实际清单绘制。
- 建议图层 DIE_OUTLINE、DIE_WORK、DIE_GUIDE、DIE_FASTENER、DIE_DIM、DIE_TEXT、DIE_AUX；已有标准优先，不强加空图层。
- 先建立基准与轮廓，再绘制已确认的导向/定位与紧固，最后补原生标注和技术要求。检查孔/刃口间距、闭合轮廓、对称关系及实际干涉，不添加客户未要求的结构。
- 材料、热处理、间隙和配合等说明以客户已确认依据为准；不确定的工程条件如实标识。

## 保存后验证

用客户所需对象和尺寸建立验收清单，回读几何、原生实体、图层、文字、单位、闭合轮廓和最终格式。不得以“至少 40 个对象”或固定词语列表判断所有模具图质量，也不因对象数量不足就重新生成整张图。

真实设计还需相应工艺/结构复核；数据库 AUDIT 和视觉预览均不能证明可生产。明确区分图纸制作完成、已执行的检查及尚未完成的工程验证。
