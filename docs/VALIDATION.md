日期：2026-11-06。验证环境：Windows、Python 3.12、AutoCAD 2026。

- 在新的仓库内 `.venv` 中从 Python 包源安装依赖，使用隔离的客户端配置和 skills 目录完成安装，`--check` 通过。
- stdio MCP 初始化、工具发现通过，共 35 个工具；`--connect` 只读图层查询通过。

## v0.2.0 按任务选路与精简入口

- cad-automation 1.3.0、cad-designer 1.2.0：由需求、原图结构和交付格式选择程序化 DXF、原生 CAD/MCP 或混合路线；详细知识按需读取。两套入口合计由 64,828 降至 12,550 UTF-8 bytes，约减少 81%。这是入口文本体积，未做 Token/耗时基准测试，实际成本取决于任务、客户端和模型。
- 两套 skills 的格式校验通过；仓库与本机技能的相对引用均检查，程序化参考中的可运行示例生成、保存和回读检查通过。
- 独立 Agent 依照新 skill 完成 120×80 mm 板、4×Ø8 孔（距边12 mm）及长宽原生 DIMENSION 的 DXF。回读验证轮廓、孔位/半径、单位、两个尺寸测量值、ByLayer 与数据库审计，无需 CAD/MCP。此测试未验证原生 CAD 打开或人工视觉效果，不生成未要求的 PDF。
- 另外复核含动态块/布局的局部 DWG 改字、无尺寸透视照片、仅有 ezdxf 却必需 DWG+PDF、1000孔批量 DXF 四类路由；修订全图验收规则，避免扩大局部改图范围。这些是规则复核，不能当作四类任务均已实测。
- 既有 56 项测试及 35 工具 MCP 协议检查通过；本次不改 MCP 运行逻辑、依赖或 CAD 安装配置，不重复宣称已实测全部 CAD 命令。
