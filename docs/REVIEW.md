# v0.1.3 再次审查记录

日期：2026-11-06。审查对象：代画匠的安装器、MCP 源码、两套 skills、配置与发布包。以下问题均已复现后修复，原上游作者与 MIT 许可保持不变。

| 问题 | 原有影响 | 修正与回归依据 |
| --- | --- | --- |
| Windows junction 绕过路径检查 | 安装或卸载可能跟随目录联接，触及 skills 目录外的文件 | 检查 Windows reparse point，保护源目录与目标链；真实 junction 回归确认外部文件保留 |
| 安装、升级或卸载中途失败 | 已写配置/skill 与最后才写入的归属清单不一致，再次运行被拒绝 | 多文件操作失败时逆序恢复配置、skills、清单及新建目录；分别模拟三个流程的故障并验证可重试 |
| 多客户端共用 skills 后更新 | 另一个客户端留着旧哈希，无法更新或完整卸载 | 同步共享归属记录；兼容旧版本已产生的不一致记录，仍拒绝真实用户改动 |
| skills 中的启动清理循环与超范围操作 | 非空图上的循环可能不结束；全删选择集、关文档、全开图层会干扰任务外状态 | 移除循环和全局清理要求；仅清理任务自建选择集，异常时恢复 OSMODE，按任务范围整理图纸 |
| 文件扩展名未决定实际保存格式 | .dxf 路径可能仍按默认 DWG 保存 | 明确使用 2018 DWG/DXF 的 SaveAs 类型，拒绝未支持的扩展名；实际保存、DXF 回读和 DWG 重开验证通过 |
| 默认图层和样式依赖过期缓存/用户当前设置 | 新实体可能落在旧图层或继承硬编码颜色、线型、线宽 | 每次读取会话目标的当前层；新建实体明确三项随层，显式颜色/线宽参数仍受尊重 |
| 窗口与会话目标不一致、失效引用未清理 | 截图/视图/命令与几何可能指向不同文档；关闭后可能误接管其他图纸 | 固定会话目标，窗口级操作先激活同一目标；目标关闭或失效后要求显式 new/open，失败也不接管其他文档 |
| 创建或阵列中途失败留存实体，部分查询仍报成功 | 重试可能产生重复对象，查询失败可能伪装为空图块列表 | 仅清理本次新建对象与复制件，不动源对象；图块枚举错误继续传播；撤销/重做只报告命令已提交 |
| 配置文件损坏/部分配置丢失环境覆盖、相对输出漂移 | 指定的 CAD 类型/输出目录被忽略，或输出落到客户端工作目录 | 合并独立默认值并统一应用环境覆盖；未知 CAD 类型明确报错，相对输出固定以仓库为基准 |

实现见 [安装器](../scripts/install.py)、[CAD 控制器](../vendor/cad-mcp/src/cad_controller.py)、[MCP 服务](../vendor/cad-mcp/src/server.py)、[配置加载](../vendor/cad-mcp/src/config.py) 与 [skills](../skills/cad-automation/SKILL.md)。

## 验证

- 56 项本地回归通过：29 项安装器、17 项 CAD 控制器/服务、6 项配置、3 项 ProgID、1 项离线 DXF。
- 默认 stdio MCP 初始化和工具发现通过，共 35 个工具，不启动 CAD。
- AutoCAD 2026 原生集成：在独立测试图中绘制 100×60 矩形、半径 10 圆与原生尺寸，保存 DWG/DXF，DXF 审计及图层/随层属性/几何检查通过；重新打开 DWG 后清点到相同 3 个实体。
- 原生测试模拟用户切换窗口及当前图层，验证命令仍指向会话目标、缺省图层取目标实际值；最终测试图清理完成，原有文档保留。
- 两套 skills 的 quick_validate、8 处相对引用及 git diff --check 通过；选择集异常清理、OSMODE 恢复示例经 mock 执行。
- 独立下载 v0.1.2 ZIP 的 CRC、文件清单及 SHA256 通过，未发现已跟踪内容含私人图纸、凭据或维护者机器专属路径；v0.1.3 下载包另附 SHA256。
- GitHub Actions 覆盖 Windows/Linux × Python 3.11/3.12，结果以 [Actions](https://github.com/Rain-dust/daihua-cad/actions) 中对应提交为准。

## 验证边界

真实 CAD 集成覆盖上述基础图元与保存、回读、目标切换；COM 失败、回滚和阵列中断主要通过隔离 mock/故障注入验证。未逐项在真实 CAD 上测试全部 35 个工具、所有 AutoLISP 示例、PDF 打印、复杂图纸、中望/浩辰或 AutoCAD LT。文件回滚处理正常进程内的文件操作异常，不保证断电或强杀后的自动恢复。客户交付仍须按任务验证几何、语义图层、尺寸及视觉结果。

CAD 清理本身若因断连等原因失败，会记录警告；重试前仍应清点目标图纸，不把失败后的重发当作自动回滚证明。
